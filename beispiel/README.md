# A real example: one round of work

These two files are the real documents of one round. They are copied from the private code repo, **unchanged except
for redactions**.

| File | What it is |
|---|---|
| [`HANDOFF-design-52.md`](HANDOFF-design-52.md) | **Handoff**: the task brief the Master wrote for the role *Design*. Goal, my decisions, what to read first, the task in numbered points, limits, and which files the role may change. |
| [`ABSCHLUSS-design-52.md`](ABSCHLUSS-design-52.md) | **Completion report** (*Abschluss*): what the role changed, how it works, the choices it made and why, how it checked its own work, and open questions for the Master. |

**Which round:** Design 52, on 2026-11-10. It is the round that built the first version of this showcase: README,
architecture diagram, screenshots. The Master then reviewed it, changed two lines, and published it after my go.

**Language:** both texts are in German. German is the working language of the whole system; Masters and roles write
everything in German.

**Redacted:** wherever a text named my domain, an address in my home network or a server provider, it now says
`[entfernt]` ("removed"). In this round that is only the list of search words the role used to check that nothing
private was published. Everything else is as written, including file paths on my PC and my first name.
